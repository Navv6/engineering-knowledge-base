## 0. 한눈에 보기 (입문)

### 한 줄 요약
**미분**은 "지금 이 순간 값이 얼마나 빠르게 변하나(기울기)"를 구하는 계산이고, **경사하강법**은 그 기울기를 보고 "내리막 쪽으로 한 걸음씩" 움직여 가장 낮은 곳(오차가 가장 작은 곳)을 찾는 방법이다. AI 모델 학습은 거의 전부 이 원리로 돌아간다.

### 쉬운 설명
안개가 짙은 산에서 가장 낮은 골짜기로 내려가야 한다고 하자. 멀리는 안 보이고 발밑만 보인다.

1. 발밑의 경사를 느낀다. 어느 쪽이 내리막인지.
2. 내리막 쪽으로 한 걸음 간다.
3. 다시 경사를 느끼고, 또 한 걸음.
4. 경사가 거의 평평해지면 골짜기 바닥이다.

여기서 **발밑의 경사**가 미분(기울기)이고, 이 반복이 경사하강법이다. **한 걸음의 크기**(학습률)가 중요하다. 너무 작으면 하루 종일 걸리고, 너무 크면 골짜기를 건너뛰어 반대편 비탈로 올라가 버린다.

**미분을 숫자로 느껴 보기:** 자동차가 3초 동안 90m를 갔다면 평균 속도는 초속 30m다. 그런데 "정확히 2초가 되는 순간"의 속도는? 2초에서 2.1초 사이, 2초에서 2.01초 사이처럼 구간을 점점 줄여 평균 속도를 구하면 어떤 값에 가까워진다. 그 값이 순간 속도, 즉 미분이다.

### 내 프로젝트에서는
- **DeepVi와 STT에서 쓴 모델은 모두 경사하강법으로 학습된 결과물이다.** DeepVi의 임베딩 모델 intfloat/multilingual-e5-large, 답변을 만든 GPT-4o, STT 평가의 NeMo Conformer CTC와 Whisper-small-ko Fine-tuned는 수억 개 이상의 숫자(가중치)를 "오차가 줄어드는 방향"으로 조금씩 고치며 학습되었다. 프로젝트에서 직접 모델을 학습시킨 기록은 없지만, "미세조정(fine-tuned)"이라는 말은 이미 학습된 가중치에서 출발해 새 데이터로 경사하강법을 더 돌렸다는 뜻이다.
- **STT의 RTF는 기울기 감각으로 읽을 수 있다.** 처리 시간 = RTF × 음성 길이라면, RTF는 "음성이 1초 늘 때 처리 시간이 몇 초 느는가"인 기울기다(MATH-BASE-001). NeMo Conformer CTC의 RTF 0.0216은 음성 1초당 처리 시간 약 0.02초 증가를 뜻한다(포트폴리오 기재값).
- **Preflight에는 미분이 쓰인 기록이 없다.** 다만 OR-OPT-001의 최적화 문제가 "목적함수를 최소화하는 값 찾기"라는 점에서 같은 질문이다.

### 먼저 알면 좋은 것
- 함수와 그래프 읽기(MATH-BASE-001): 기울기 = 세로 변화 ÷ 가로 변화

## 1. 핵심 요약

- **미분(도함수):** $f'(x) = \lim_{h \to 0} \dfrac{f(x + h) - f(x)}{h}$. 아주 짧은 구간의 평균 기울기의 극한.
- **기본 규칙:** $(x^n)' = n x^{n-1}$, $(c f)' = c f'$, $(f + g)' = f' + g'$, 연쇄 법칙 $(f(g(x)))' = f'(g(x))\, g'(x)$.
- **최솟값:** 매끄러운 함수의 최솟값에서는 기울기가 0이다($f'(x) = 0$). 반대는 항상 성립하지 않는다(최댓값, 평평한 점).
- **편미분과 그래디언트:** 변수가 여럿이면 하나씩 미분한 값을 모은 벡터 $\nabla f$. 가장 가파르게 올라가는 방향을 가리킨다.
- **경사하강법:** $w \leftarrow w - \eta \nabla f(w)$. 기울기의 반대 방향으로 학습률 $\eta$만큼 이동.
- **학습률:** 작으면 느리고, 크면 진동·발산. 딥러닝에서는 데이터 일부로 기울기를 추정하는 확률적 경사하강법(SGD)과 그 변형(Adam 등)을 쓴다.

## 2. 개념과 등장 배경

17세기 후반 아이작 뉴턴(Isaac Newton)과 고트프리트 라이프니츠(Gottfried Leibniz)가 독립적으로 미적분을 만들었다. 뉴턴은 움직이는 물체의 속도를, 라이프니츠는 곡선의 접선을 구하려 했다. 오늘 쓰는 $\dfrac{dy}{dx}$ 기호는 라이프니츠의 것이다. 19세기 코시(Cauchy)와 바이어슈트라스(Weierstrass)가 극한을 엄밀하게 정의해 미분의 논리적 기초를 세웠다.

경사하강법은 1847년 오귀스탱 코시가 연립 방정식을 푸는 방법으로 제안했다. 이 오래된 아이디어가 20세기 후반 신경망 학습의 중심이 되었다. 1986년 럼멜하트(Rumelhart), 힌턴(Hinton), 윌리엄스(Williams)가 대중화한 **역전파**(backpropagation)는 연쇄 법칙을 이용해 수많은 가중치의 기울기를 한꺼번에 효율적으로 계산하는 방법이다. 오늘날의 LLM도 이 조합으로 학습된다.

## 3. 직관적 설명 및 기초 이론

### 평균 기울기에서 순간 기울기로

$f(x) = x^2$에서 $x = 3$일 때의 기울기를 구해 보자. $x = 3$에서 $h$만큼 떨어진 점까지의 평균 기울기:

| $h$ | $\dfrac{f(3 + h) - f(3)}{h}$ |
|---|---|
| 1 | $(16 - 9)/1 = 7$ |
| 0.1 | $(9.61 - 9)/0.1 = 6.1$ |
| 0.01 | $(9.0601 - 9)/0.01 = 6.01$ |
| 0.001 | $6.001$ |

$h$를 줄일수록 6에 가까워진다. 그래서 $x = 3$에서 $x^2$의 순간 기울기는 6이다. 규칙 $(x^2)' = 2x$로 계산해도 $2 \times 3 = 6$이다.

### 기울기의 부호가 알려 주는 것

| $f'(x)$ | 그래프 | 최솟값을 찾으려면 |
|---|---|---|
| 양수 | 오른쪽으로 갈수록 올라감 | 왼쪽으로(값을 줄여라) |
| 음수 | 오른쪽으로 갈수록 내려감 | 오른쪽으로(값을 키워라) |
| 0 | 평평 | 도착했을 수 있음 |

"기울기의 **반대** 방향으로 가라"가 경사하강법의 전부다. 기울기가 클수록(가파를수록) 한 번에 많이 움직인다.

## 4. 엄밀한 정의와 작동 원리

### 도함수

$$
f'(x) = \frac{df}{dx} = \lim_{h \to 0} \frac{f(x + h) - f(x)}{h}
$$

예: $f(x) = x^2$이면 $\dfrac{(x + h)^2 - x^2}{h} = \dfrac{2xh + h^2}{h} = 2x + h \to 2x$.

### 자주 쓰는 규칙

| 함수 | 도함수 |
|---|---|
| $c$ (상수) | $0$ |
| $x^n$ | $n x^{n-1}$ |
| $e^x$ | $e^x$ |
| $\ln x$ | $1/x$ |
| $c\,f(x)$ | $c\,f'(x)$ |
| $f(x) + g(x)$ | $f'(x) + g'(x)$ |
| $f(g(x))$ (연쇄 법칙) | $f'(g(x))\,g'(x)$ |

연쇄 법칙 예: $(3x + 1)^2$의 미분은 바깥 $u^2$의 미분 $2u$에 안쪽 $3x + 1$의 미분 3을 곱해 $2(3x + 1) \times 3 = 6(3x + 1)$. 신경망은 함수가 수십 겹 겹친 구조라서, 역전파는 이 연쇄 법칙을 층마다 반복 적용한다. 지수와 로그의 미분(MATH-BASE-002)은 확률 모델의 손실 함수에서 자주 나온다.

### 편미분과 그래디언트

$f(x, y) = x^2 + 2y^2$처럼 변수가 둘이면, 다른 변수는 상수로 두고 하나씩 미분한다:

$$
\frac{\partial f}{\partial x} = 2x, \qquad \frac{\partial f}{\partial y} = 4y, \qquad \nabla f = (2x,\ 4y)
$$

점 $(1, 1)$에서 $\nabla f = (2, 4)$: 이 방향이 가장 가파른 오르막이고, $(-2, -4)$ 방향이 가장 가파른 내리막이다. 그래디언트는 벡터(MATH-LA-001)다.

### 경사하강법

$$
w_{k+1} = w_k - \eta \, \nabla f(w_k)
$$

$\eta$(에타)는 학습률. 함수가 볼록하고(그릇 모양) 학습률이 적당하면 최솟값으로 수렴한다. 볼록하지 않으면(신경망) 지역 최솟값이나 안장점에 머물 수 있지만, 실무에서는 충분히 좋은 해에 도달하는 경우가 많다.

### 확률적 경사하강법 (SGD)

손실이 데이터 $n$개의 오차 평균 $L(w) = \dfrac{1}{n}\sum_i \ell_i(w)$일 때, 매번 전체의 기울기를 구하는 대신 무작위로 뽑은 작은 묶음(미니배치)의 기울기로 근사한다. 계산이 훨씬 싸고, 약간의 잡음이 지역 최솟값을 벗어나는 데 도움이 되기도 한다. 합 기호(MATH-BASE-003)가 여기서 쓰인다.

## 5. 수식 및 기호 설명

| 기호 | 읽는 법 | 뜻 |
|---|---|---|
| $f'(x)$, $\dfrac{df}{dx}$ | "에프 프라임", "디에프 디엑스" | 도함수(기울기) |
| $\lim_{h \to 0}$ | "h가 0으로 갈 때의 극한" | 한없이 가까워지는 값 |
| $\dfrac{\partial f}{\partial x}$ | "편미분 에프 엑스" | 다른 변수는 고정하고 $x$로 미분 |
| $\nabla f$ | "나블라 에프", "그래디언트" | 편미분을 모은 벡터 |
| $\eta$ | "에타" | 학습률(한 걸음 크기) |
| $w$ | | 고칠 값(모델의 가중치) |

## 6. 단계별 계산 또는 동작 예제

### 예제 1. 최솟값을 미분으로 찾기

$f(w) = (w - 3)^2$. 연쇄 법칙으로 $f'(w) = 2(w - 3)$. $f'(w) = 0$을 풀면 $w = 3$. 이 함수는 그릇 모양이라 $w = 3$이 최솟값이고, $f(3) = 0$이다. 이처럼 식이 간단하면 미분해서 바로 풀 수 있다. 회귀분석의 최소제곱법도 이 방식으로 공식이 나온다(STAT-REG-001).

### 예제 2. 같은 문제를 경사하강법으로

$w_0 = 0$, 학습률 $\eta = 0.1$. 매 단계 $w \leftarrow w - 0.1 \times 2(w - 3)$.

| 단계 | 기울기 $2(w - 3)$ | 새 $w$ |
|---|---|---|
| 0 | | 0 |
| 1 | $-6$ | $0 + 0.6 = 0.6$ |
| 2 | $-4.8$ | $0.6 + 0.48 = 1.08$ |
| 3 | $-3.84$ | $1.08 + 0.384 = 1.464$ |
| 4 | $-3.072$ | $1.7712$ |
| 5 | $-2.4576$ | $2.01696$ |

목표 3과의 거리가 매 단계 0.8배로 준다($3 - w_k = 3 \times 0.8^k$). 식으로 바로 풀 수 없는 복잡한 함수(신경망)에서도 이 반복은 그대로 쓸 수 있다는 것이 경사하강법의 힘이다.

### 예제 3. 학습률이 너무 크면

같은 문제에서 $\eta = 1.1$:

| 단계 | $w$ | 3과의 거리 |
|---|---|---|
| 0 | 0 | 3 |
| 1 | 6.6 | 3.6 |
| 2 | $-1.32$ | 4.32 |
| 3 | 8.184 | 5.184 |
| 4 | $-3.2208$ | 6.2208 |

최솟값을 건너뛰며 좌우로 튀고, 거리가 매번 1.2배로 커져 **발산**한다. 이 문제에서는 $0 < \eta < 1$이면 수렴하고, $\eta = 0.5$면 한 번에 정확히 3에 도착한다. 실제 모델에서는 이런 값을 미리 알 수 없어서 여러 학습률을 시험하거나, 학습 중 학습률을 줄여 가는 방법을 쓴다.

### 예제 4. 두 변수에서 한 걸음

$f(x, y) = x^2 + 2y^2$, 시작점 $(1, 1)$, $\eta = 0.1$.

- 그래디언트: $(2 \times 1,\ 4 \times 1) = (2, 4)$
- 새 점: $(1 - 0.2,\ 1 - 0.4) = (0.8,\ 0.6)$
- 값: $f(1, 1) = 3$ → $f(0.8, 0.6) = 0.64 + 0.72 = 1.36$

$y$ 방향이 더 가팔라서(계수 2) $y$가 더 많이 줄었다.

## 7. 시각화와 해석

$f(w) = (w - 3)^2$의 그래프(그릇 모양)에 예제 2의 점들을 찍으면, 왼쪽 비탈에서 바닥을 향해 걸음이 점점 짧아지며 다가가는 모습이 보인다. 바닥에 가까울수록 기울기가 작아져 자동으로 걸음이 줄어든다. 예제 3의 점들은 바닥을 사이에 두고 양쪽 비탈을 오가며 점점 높이 올라간다. 두 변수 함수는 등고선 지도로 그리면, 그래디언트의 반대 방향이 등고선에 수직으로 내려가는 방향임을 볼 수 있다. Big-O 시각화(CS-ALG-002)의 함수 그래프 읽기와 같은 방식으로 따라 그릴 수 있다.

| 방법 | 쓰는 정보 | 장점 | 단점 | 쓰임 |
|---|---|---|---|---|
| 식을 미분해 0인 점 풀기 | 도함수 식 | 정확, 한 번에 | 간단한 식만 가능 | 최소제곱 회귀 |
| 경사하강법 | 기울기 | 어떤 미분 가능한 함수에도 | 학습률 조정, 느릴 수 있음 | 신경망 학습 |
| SGD·Adam | 미니배치 기울기 | 대용량 데이터에 적합 | 잡음, 설정값 | 딥러닝 표준 |
| 뉴턴 방법 | 기울기 + 곡률(2차 미분) | 빠른 수렴 | 변수가 많으면 계산 비쌈 | 작은 통계 모델 |

## 9. 실무 사례

- **신경망 학습:** 손실 함수(예측과 정답의 차이)를 가중치에 대해 미분해(역전파) 경사하강법으로 줄인다. 학습 곡선(단계별 손실)이 내려가지 않거나 튀면 학습률부터 의심한다.
- **미세조정:** 사전 학습된 모델에서 출발해 작은 학습률로 도메인 데이터에 맞춘다. 학습률이 크면 원래 능력을 잃는다(파국적 망각).
- **가격·수요 분석:** 이익 함수를 가격으로 미분해 이익이 최대가 되는 가격을 찾는다.
- **민감도:** "이 입력이 조금 바뀌면 결과가 얼마나 바뀌나"는 미분이다(OR-OPT-001의 잠재가격도 같은 의미).

## 10. 기존 프로젝트와의 연결

아래 사실은 포트폴리오·저장소 원문(`content/profile.json`)에서 옮긴 것이다. 프로젝트에서 모델을 직접 학습시킨 기록은 없다.

- **DeepVi:** 임베딩 모델 intfloat/multilingual-e5-large(HuggingFaceEmbeddings)와 GPT-4o를 썼다. 두 모델 모두 대규모 데이터에 경사하강법 계열 최적화로 학습된 결과물을 가져다 쓴 것이다. 임베딩 모델의 학습 목표(비슷한 문장은 가깝게)도 미분 가능한 손실 함수로 표현된다(AI-EMB-001).
- **STT 평가:** NeMo Conformer CTC(WER 0.226), Whisper-small-ko Fine-tuned(WER 0.239) 등을 비교했다. "Fine-tuned"는 Whisper small 모델을 한국어 데이터로 경사하강법을 더 돌려 맞춘 모델이라는 뜻이다(누가 미세조정했는지는 기재 없음). CTC라는 이름의 학습 방법도 "정답 문장이 나올 확률"을 미분 가능한 손실로 만든 것이다(AI-ASR-001).
- **RTF와 기울기:** RTF는 처리 시간을 음성 길이로 미분한 값(직선이라면 기울기)으로 해석할 수 있다.

## 11. 가정·한계·흔한 오해·트레이드오프

- **오해: 기울기가 0이면 최솟값이다.** 최댓값이거나 평평한 안장점일 수 있다. 그릇 모양(볼록) 함수에서만 기울기 0이 곧 최솟값이다.
- **오해: 경사하강법은 항상 가장 좋은 답을 찾는다.** 볼록하지 않은 함수에서는 지역 최솟값에 머물 수 있다.
- **미분 불가능한 곳:** $|x|$의 $x = 0$처럼 뾰족한 점에서는 미분이 정의되지 않는다. 실무에서는 하위 기울기 같은 방법으로 처리한다.
- **변수 크기 차이:** 한 변수는 0~1, 다른 변수는 0~100만 범위면 그래디언트가 한쪽으로 치우쳐 학습이 느려진다. 입력을 비슷한 범위로 맞추는(정규화) 이유다.
- **수치 미분의 오차:** 3절처럼 작은 $h$로 근사하면 $h$가 너무 작을 때 컴퓨터 반올림 오차가 커진다. 실제 학습은 식으로 계산한 기울기(자동 미분)를 쓴다.

## 12. 이해 확인 및 면접 질문

<details class="qa" data-type="concept"><summary>Q1. $f(x) = 3x^2 + 2x$의 도함수와 $x = 1$에서의 기울기는?</summary>

**정답.** $f'(x) = 6x + 2$, $x = 1$에서 8.

**해설.** 거듭제곱 규칙과 상수배·합의 규칙을 쓴다. $(3x^2)' = 6x$, $(2x)' = 2$.

</details>

<details class="qa" data-type="concept"><summary>Q2. $f(w) = (w - 5)^2$에서 $w = 1$, 학습률 0.25로 경사하강법 한 걸음을 가면 새 $w$는?</summary>

**정답.** 기울기 $2(1 - 5) = -8$, 새 $w = 1 - 0.25 \times (-8) = 3$.

**해설.** 기울기가 음수이므로 $w$를 키우는 방향으로 이동한다. 목표 5와의 거리가 4에서 2로 절반이 되었다.

</details>

<details class="qa" data-type="judgment"><summary>Q3. 모델 학습 중 손실 값이 내려가다가 갑자기 커지며 위아래로 튄다. 무엇을 의심하고 어떻게 하겠는가?</summary>

**정답.** 학습률이 너무 커서 최솟값 주변을 건너뛰거나 발산하는 상황을 먼저 의심한다. 학습률을 낮추거나 학습 중 점점 줄이는 일정을 쓰고, 기울기 크기를 제한(gradient clipping)하며, 입력 정규화와 데이터 이상치도 확인한다.

**해설.** 예제 3의 발산과 같은 현상이다.

</details>

<details class="qa" data-type="applied"><summary>Q4. "미세조정된 모델"을 쓸지 원래 모델을 쓸지 고를 때, 경사하강법 관점에서 확인할 점은?</summary>

**정답.** 어떤 데이터로 얼마나 학습했는지(평가 데이터와 겹치지 않는지), 학습률이 커서 원래 능력을 잃지 않았는지(일반 데이터에서도 성능 확인), 그리고 같은 평가 조건에서 실제로 나아졌는지를 확인한다.
