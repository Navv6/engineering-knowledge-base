## 0. 한눈에 보기 (입문)

### 한 줄 요약
**미세조정**은 이미 많이 배운 모델(사전 학습 모델)을 내 분야의 데이터로 조금 더 가르쳐 특정 일에 맞추는 것이고, **LoRA**는 모델 전체를 고치는 대신 작은 "덧붙이는 부품"만 학습해 비용을 크게 줄이는 방법이다.

### 쉬운 설명
경력 많은 요리사를 한식당에 데려왔다고 하자.

- **사전 학습:** 요리 학교와 여러 식당에서 쌓은 기본기(칼질, 불 조절, 수천 가지 요리).
- **프롬프트·RAG:** 매번 주문서와 레시피 카드를 건네는 것. 요리사 자체는 바뀌지 않는다.
- **미세조정:** 몇 주간 우리 식당 메뉴만 집중 연습시키는 것. 우리 식당 스타일이 몸에 밴다.
- **LoRA:** 요리사의 기본기는 그대로 두고, 우리 식당용 "작은 메모장"만 새로 익히게 하는 것. 메모장만 바꾸면 다른 식당 스타일로도 쉽게 갈아 끼운다.

너무 오래, 너무 강하게 연습시키면 기본기를 잊는다(**파국적 망각**). 연습 문제와 시험 문제가 같으면 실력이 늘었는지 알 수 없다(**평가 데이터 누출**).

### 내 프로젝트에서는
- **STT 평가에 미세조정된 모델이 있었다.** 4종 비교에서 Whisper-small-ko Fine-tuned는 WER 0.239·CER 0.1246·RTF 0.0623으로, 더 큰 범용 모델인 Faster-Whisper Medium(WER 0.5001, CER 0.2937, RTF 0.2493)보다 정확하고 빨랐다(포트폴리오 기재). 작은 모델이라도 한국어 데이터로 맞추면 큰 범용 모델을 앞설 수 있다는 사례다. 다만 누가 어떤 데이터로 미세조정했는지는 기재가 없어, **평가 데이터(KsponSpeech)와 겹치는 데이터로 학습했는지** 확인해야 공정한 비교인지 판단할 수 있다(6절 예제 3).
- **STT 로컬 LLM 검토는 미세조정 없이 기존 모델을 평가했다.** Qwen2.5-7B-Instruct와 vLLM으로 JSON 스키마 유지·요약 품질·처리 시간·실패 대응을 검토했다(포트폴리오 기재). "프롬프트로 되는지 먼저 보고, 안 되면 미세조정"이라는 순서의 첫 단계다.
- **DeepVi는 미세조정 없이 RAG를 썼다.** GPT-4o에 검색한 뉴스·기업 정보를 넣어 답했다(저장소 기재). 매일 바뀌는 뉴스 같은 최신 지식에는 미세조정보다 RAG가 맞다(8절).

### 먼저 알면 좋은 것
- LLM과 트랜스포머 작동 원리(AI-LLM-001): 사전 학습, 가중치 행렬
- 미분과 경사하강법(MATH-CALC-001): 학습 = 경사하강법으로 가중치 고치기, 학습률

## 1. 핵심 요약

- **전이 학습:** 큰 데이터로 사전 학습한 모델을 출발점으로, 작은 도메인 데이터로 추가 학습한다(ULMFiT 2018 이후 NLP 표준).
- **전체 미세조정:** 모든 가중치를 고친다. 성능 상한이 높지만 GPU 메모리·저장 비용이 크고 망각 위험이 크다.
- **LoRA:** 원래 가중치 $W$는 고정하고, 작은 두 행렬의 곱 $BA$(순위 $r$)만 학습해 $W + BA$로 쓴다. 학습 매개변수가 1% 미만으로 줄 수 있다.
- **QLoRA:** 원래 모델을 4비트로 압축(양자화)해 올리고 LoRA를 학습해 메모리를 더 줄인다.
- **언제 쓰나:** 프롬프트·예시·RAG로 안 되는 일관된 형식·말투·분류 기준, 도메인 특화 음성·용어. 최신 지식 주입에는 RAG가 우선.
- **위험:** 과적합, 파국적 망각, 평가 데이터 누출, 데이터의 개인정보·저작권, 모델 갱신 시 재학습.

## 2. 개념과 등장 배경

컴퓨터 비전에서는 2010년대 초부터 ImageNet으로 사전 학습한 모델을 다른 이미지 과제에 맞춰 쓰는 전이 학습이 표준이었다. 2018년 하워드(Howard)와 루더(Ruder)의 ULMFiT, 같은 해 BERT·GPT가 언어 모델에서도 "사전 학습 후 미세조정"이 강력함을 보이며 NLP의 방식이 바뀌었다.

모델이 수십억~수천억 매개변수로 커지자 전체 미세조정은 비용이 너무 커졌다. 2021년 휴(Hu) 등의 **LoRA**는 미세조정 때 가중치 변화가 "낮은 순위" 행렬로 잘 근사된다는 관찰에서, 작은 행렬 두 개만 학습하는 방법을 제안했다. 2023년 **QLoRA**는 4비트 양자화와 결합해 큰 모델도 단일 GPU에서 미세조정할 수 있게 했다. 음성 인식에서는 Whisper 같은 다국어 모델을 특정 언어·분야 데이터로 미세조정한 공개 모델이 많이 나왔다.

## 3. 직관적 설명 및 기초 이론

### 프롬프트, RAG, 미세조정

| 방법 | 바꾸는 것 | 장점 | 한계 |
|---|---|---|---|
| 프롬프트·예시 | 입력 | 즉시, 비용 없음 | 긴 지시는 비용·지연, 일관성 한계 |
| RAG | 입력에 넣는 근거 | 최신·사내 지식, 출처 | 검색 품질에 좌우(AI-RAG-001) |
| 미세조정(LoRA) | 모델 일부 | 형식·말투·판단 기준이 몸에 뱀, 짧은 프롬프트 | 데이터·학습·평가 비용, 지식 갱신 어려움 |
| 전체 미세조정 | 모델 전체 | 최대 적응 | 비용·망각·관리 부담 |

### LoRA의 직관

모델의 한 층은 큰 행렬 $W$(예: 4096 × 4096)다. 미세조정으로 생기는 변화 $\Delta W$도 같은 크기지만, 실제로는 "몇 가지 방향"의 변화로 대부분 설명된다는 것이 LoRA의 가정이다. 그래서 $\Delta W$를 (4096 × $r$)과 ($r$ × 4096) 두 개의 얇은 행렬 곱으로 표현한다(MATH-LA-002). $r = 8$이면 학습할 숫자가 크게 줄어든다.

## 4. 엄밀한 정의와 작동 원리

### LoRA

원래 가중치 $W_0 \in \mathbb{R}^{d \times k}$를 고정하고

$$
h = W_0 x + \Delta W x = W_0 x + B A x, \qquad B \in \mathbb{R}^{d \times r},\ A \in \mathbb{R}^{r \times k},\ r \ll \min(d, k)
$$

$A$, $B$만 경사하강법으로 학습한다(MATH-CALC-001). 학습 매개변수 수는 $dk$에서 $r(d + k)$로 준다. 학습이 끝나면 $W_0 + BA$를 합쳐 추론 속도 손실 없이 쓸 수 있고, 과제별로 작은 $A, B$만 바꿔 끼울 수 있다.

### 학습 목표

언어 모델 미세조정은 정답 출력 토큰의 교차 엔트로피(MATH-INFO-001)를 최소화한다. 지시 미세조정 데이터는 (지시·입력, 기대 출력) 쌍이고, 보통 기대 출력 부분의 손실만 계산한다.

### 과적합과 망각

- **과적합:** 학습 손실은 계속 내려가는데 검증 손실이 다시 오른다 → 학습 중단(조기 종료), 데이터 늘리기, 학습률 낮추기.
- **파국적 망각:** 새 과제 데이터만으로 강하게 학습하면 원래 능력(일반 대화, 다른 언어)이 떨어진다 → 낮은 학습률, LoRA처럼 원래 가중치 고정, 일반 데이터 일부 섞기, 일반 능력 평가 세트로 감시.

### 데이터 분리

학습 / 검증(설정 고르기) / 시험(최종 평가)을 나누되, 같은 출처(같은 화자의 다른 발화, 같은 문서의 다른 문단)가 서로 다른 세트에 들어가지 않게 **그룹 단위로** 나눈다. 그렇지 않으면 시험 점수가 부풀려진다.

## 5. 수식 및 기호 설명

| 기호 | 뜻 |
|---|---|
| $W_0$ | 고정된 원래 가중치 행렬 |
| $\Delta W = BA$ | 학습되는 저순위 변화 |
| $r$ | LoRA 순위(작을수록 매개변수 적음) |
| $d, k$ | 가중치 행렬의 크기 |
| $r(d + k)$ | LoRA 학습 매개변수 수 |
| 양자화 | 가중치를 적은 비트(예: 4비트)로 저장 |

## 6. 단계별 계산 또는 동작 예제

### 예제 1. LoRA 매개변수 수

4096 × 4096 가중치 행렬 하나:
- 전체 미세조정: $4096 \times 4096 = 16{,}777{,}216$개
- LoRA $r = 8$: $8 \times (4096 + 4096) = 65{,}536$개 → 전체의 약 **0.39%**

모델의 여러 층에 LoRA를 붙여도 학습할 숫자는 원래 모델의 작은 일부다. 저장도 과제별로 작은 파일 하나면 된다.

### 예제 2. 메모리 감각

매개변수 70억 개(7B, STT 로컬 LLM 검토의 Qwen2.5-7B급) 모델의 가중치만 올리는 데:
- 16비트(2바이트): $7 \times 10^9 \times 2 = 14$GB
- 4비트(0.5바이트): 약 3.5GB

전체 미세조정은 여기에 기울기·최적화 상태가 더해져 몇 배가 필요하다. QLoRA는 4비트 모델 + 작은 LoRA 행렬만 학습해 일반 GPU 한 장에서도 가능하게 한다(정확한 요구량은 설정에 따라 다름, 확인 필요). 이 계산은 가중치 저장 공간만의 대략값이다.

### 예제 3. 미세조정 모델을 공정하게 비교하기

STT 결과(포트폴리오 기재): Whisper-small-ko Fine-tuned WER 0.239, Faster-Whisper Medium WER 0.5001. 상대적으로 약 52% 낮은 WER이다($(0.5001 - 0.239)/0.5001 \approx 0.52$).

이 차이를 "미세조정의 효과"로 해석하기 전에 확인할 것:

| 점검 | 이유 |
|---|---|
| 미세조정 학습 데이터에 KsponSpeech(평가 세트와 같은 출처)가 포함됐나 | 포함됐다면 같은 분포에 맞춘 효과가 커서 다른 데이터에서는 차이가 줄 수 있다. 평가 문장 자체가 포함됐다면 누출 |
| 두 모델의 정규화·디코딩 설정이 같은가 | 출력 표기 습관이 WER을 크게 바꾼다(AI-ASR-001 예제 3) |
| 같은 하드웨어에서 RTF를 쟀나 | 실행 엔진이 다르면 속도 비교가 왜곡 |
| 현장 데이터에서도 순위가 유지되나 | 고령 응답자 음성은 공개 데이터와 다르다 |

포트폴리오에는 이 정보가 기재되어 있지 않다. 비교 결과를 보고할 때 "학습 데이터 출처 확인 필요"를 함께 적는 것이 정확하다.

## 7. 시각화와 해석

미세조정 중에는 학습 손실과 검증 손실을 같은 그래프에 그린다. 두 선이 함께 내려가다 검증 손실만 다시 오르기 시작하는 지점이 과적합 시작이다. 과제 성능(도메인 평가)과 일반 성능(일반 평가 세트)을 단계별로 함께 그리면, 과제 성능을 얻는 대가로 일반 능력을 얼마나 잃는지(망각)가 보인다.

## 8. 기술 비교 및 선택 기준

| 원하는 것 | 먼저 시도 | 그래도 안 되면 |
|---|---|---|
| 최신·사내 지식으로 답하기 | RAG | 검색 개선(AI-RAG-001) |
| 정해진 출력 형식 | 프롬프트 + 스키마 + 검증(AI-PROMPT-001) | LoRA 미세조정 |
| 특정 말투·문체 | 예시 몇 개 | LoRA |
| 도메인 분류 기준 | few-shot + 평가 | 작은 모델 미세조정(비용·속도 이점) |
| 특정 언어·분야 음성 인식 | 범용 모델 평가 | 도메인 음성으로 미세조정 |
| 큰 모델을 싸게 운영 | 작은 모델 + 미세조정 | 증류(큰 모델 출력으로 작은 모델 학습) |

**판단 원칙:** 평가 세트를 먼저 만들고(AI-LLMEVAL-001), 프롬프트·RAG 기준선을 잰 뒤, 미세조정이 그보다 의미 있게 나을 때만 학습·운영 비용을 감수한다.

## 9. 실무 사례

- **고객 지원 분류:** 수천 건의 라벨 데이터로 작은 모델을 미세조정해 큰 모델 API보다 싸고 빠르게 분류한다.
- **도메인 음성 인식:** 의료·법률 용어가 많은 녹음으로 음성 인식 모델을 미세조정해 고유명사 오류를 줄인다.
- **사내 문서 형식 생성:** 보고서 형식을 일관되게 지키도록 LoRA로 학습하고, 내용은 RAG로 넣는다.
- **여러 과제 하나의 기반 모델:** 과제별 LoRA 파일을 바꿔 끼워 한 기반 모델로 여러 기능을 운영한다.

## 10. 기존 프로젝트와의 연결

아래 사실은 포트폴리오·저장소 원문(`content/profile.json`)에서 옮긴 것이다. 프로젝트에서 직접 미세조정을 수행한 기록은 없다.

- **STT — 미세조정 모델 비교:** Whisper-small-ko Fine-tuned(WER 0.239)가 Faster-Whisper Medium(WER 0.5001)보다 정확하고 빨랐다. 최종 판단은 정확도 중심 NeMo Conformer CTC(WER 0.226), 실시간 Riva Streaming이었다. 예제 3의 점검(학습 데이터 출처, 정규화·하드웨어 동일성)을 보고서에 덧붙이면 비교의 신뢰도가 높아진다.
- **STT — 로컬 LLM:** Qwen2.5-7B-Instruct + vLLM으로 JSON 스키마 유지 등 4개 기준을 검토했다(운영 전환 아님). 스키마 유지가 부족하다면 다음 단계로 "스키마 준수 예시로 LoRA 미세조정"을 검토할 수 있지만, 먼저 스키마 강제·검증·재시도(AI-PROMPT-001)로 충분한지 재는 것이 순서다.
- **DeepVi — RAG 선택:** 매일 수집한 뉴스와 API 재무 수치를 검색·조회해 GPT-4o에 넣었다. 지식이 매일 바뀌는 문제에 미세조정 대신 RAG를 쓴 것은 8절의 판단 기준에 맞는다.

## 11. 가정·한계·흔한 오해·트레이드오프

- **오해: 미세조정하면 모델이 새 지식을 정확히 외운다.** 사실 지식 주입은 불안정하고 환각을 줄이지 못할 수 있다. 지식은 RAG로, 방식은 미세조정으로가 흔한 원칙이다.
- **오해: 데이터가 많을수록 무조건 좋다.** 품질 낮은·일관성 없는 데이터는 모델을 망친다. 수백~수천 개의 깨끗한 예시가 수만 개의 지저분한 예시보다 나은 경우가 많다.
- **평가 누출:** 같은 출처 데이터가 학습과 시험에 섞이면 점수가 부풀려진다(예제 3).
- **유지 비용:** 기반 모델이 새 버전으로 바뀌면 다시 학습·평가해야 한다.
- **데이터 권리:** 학습 데이터의 개인정보·저작권·사용 허락을 확인한다.

## 12. 이해 확인 및 면접 질문

<details class="qa" data-type="concept"><summary>Q1. 2048 × 2048 가중치에 순위 4의 LoRA를 붙이면 학습 매개변수는 몇 개이고 전체의 몇 %인가?</summary>

**정답.** $4 \times (2048 + 2048) = 16{,}384$개, 전체 $2048^2 = 4{,}194{,}304$개의 약 0.39%.

**해설.** $r(d + k) / (dk)$. 정사각 행렬이면 $2r/d$로, $8/2048 \approx 0.0039$.

</details>

<details class="qa" data-type="concept"><summary>Q2. 미세조정 중 학습 손실은 계속 내려가는데 검증 손실이 오르기 시작했다. 무슨 일이고 어떻게 하나?</summary>

**정답.** 과적합. 학습 데이터를 외우기 시작했다. 검증 손실이 가장 낮았던 시점의 모델을 쓰고(조기 종료), 학습률·학습 횟수를 줄이거나 데이터를 늘린다.

**해설.** 검증 세트는 학습에 쓰지 않아야 이 신호가 의미 있다.

</details>

<details class="qa" data-type="judgment"><summary>Q3. 사내 규정 Q&A 챗봇이 규정 내용을 자주 틀린다. 팀원이 "규정 문서로 미세조정하자"고 한다. 어떻게 답하겠는가?</summary>

**정답.** 규정 내용(지식)을 정확히 답하게 하려면 미세조정보다 RAG(규정 원문 검색 + 인용 강제 + 근거 검증)가 먼저다. 미세조정은 지식을 안정적으로 주입하지 못할 수 있고, 규정이 바뀔 때마다 재학습해야 한다. 검색 품질과 근거 충실도를 먼저 평가하고, 말투·형식 문제가 남으면 그때 LoRA를 검토한다.

**해설.** "지식은 RAG, 방식은 미세조정"이라는 구분이다.

</details>

<details class="qa" data-type="applied"><summary>Q4. 공개된 "한국어 미세조정 음성 인식 모델"이 공개 평가 세트에서 매우 좋은 점수를 보인다. 우리 현장에 쓸지 결정하려면 무엇을 확인하겠는가?</summary>

**정답.** 학습 데이터에 그 평가 세트 또는 같은 출처가 포함됐는지(누출), 우리 현장 음성 표본(수십~수백 개)에서 같은 정규화로 CER·의미 지표를 재면 순위가 유지되는지, 같은 하드웨어에서의 속도, 라이선스와 데이터 사용 조건을 확인한다.

**해설.** STT 평가의 Whisper-small-ko Fine-tuned 비교에도 같은 점검이 필요하다(예제 3).

</details>

## 14. 참고 자료

출처는 아래 패널에 있다. LoRA 식과 저순위 가정은 Hu 외(2021), 4비트 양자화 학습은 Dettmers 외(2023), 언어 모델 전이 학습은 Howard & Ruder(2018)를 따랐다. 6절 예제 1·2의 계산(0.39%, 14GB·3.5GB, 상대 WER 차이 약 52%)은 직접 검산했다. STT 수치는 포트폴리오 기재값이며, 미세조정 모델의 학습 데이터 출처는 기재되어 있지 않다.
