## 0. 한눈에 보기 (입문)

### 한 줄 요약
**로지스틱 회귀**는 "합격할까?", "지연될까?" 같은 예/아니오 질문에 **0~1 사이 확률**로 답하는 가장 기본적인 분류 모델이다. 입력으로 점수를 계산한 뒤, 그 점수를 S자 곡선(**시그모이드**)에 넣어 확률로 바꾼다.

### 쉬운 설명
공부 시간으로 시험 합격 여부를 예측한다고 하자. 일반 회귀(직선)로 하면 "공부 10시간 → 합격 확률 140%" 같은 말이 안 되는 값이 나온다. 확률은 0과 1 사이여야 한다.

로지스틱 회귀는 두 단계로 해결한다.
1. **점수 계산:** 점수 = 기울기 × 공부 시간 + 기준점. 이 점수는 음수부터 양수까지 아무 값이나 될 수 있다.
2. **확률로 바꾸기:** 점수를 S자 곡선에 넣는다. 점수가 0이면 확률 50%, 크게 양수면 100%에 가깝게, 크게 음수면 0%에 가깝게 변한다.

결과는 "합격 확률 86%"처럼 나오고, 사람이 정한 **기준값**(예: 50%)을 넘으면 "합격"으로 판정한다. 기준값은 상황에 따라 바꾼다. 놓치면 큰일 나는 문제(불량 검출)는 기준을 낮춰 더 많이 잡고, 잘못 잡으면 비용이 큰 문제는 기준을 높인다(분류 평가 지표, AI-EVAL-001).

로지스틱 회귀의 큰 장점은 **설명하기 쉽다**는 것이다. "공부 1시간이 늘 때마다 합격 가능성(오즈)이 3.4배"처럼 각 입력의 영향을 숫자로 말할 수 있다.

### 내 프로젝트에서는
- **STT 의미 평가 — 임계값 판정:** SemWER@0.85는 문장 쌍의 의미 유사도가 0.85 이상이면 "의미가 보존됐다"로 보는 판정이다(포트폴리오 기재). 연속 점수에 기준값을 두어 예/아니오로 바꾸는 점에서 로지스틱 회귀의 마지막 단계와 같다. 포트폴리오에는 0.85를 고른 이유가 기재되어 있지 않다. 사람이 판정한 표본이 있으면 이 기준값을 근거 있게 고를 수 있다(10절).
- **Preflight — 위험도 판정:** 동기화 파이프라인에서 칸 비교 결과로 위험도를 판정해 위험한 변경만 검토 대기열로 보낸다(포트폴리오 기재). 이것은 사람이 정한 규칙이고 학습된 모델이 아니다. 업무 규칙이 분명하면 규칙이 낫다(규칙 엔진과 정책 분리, SE-RULE-001).
- **DeepVi:** 버핏·린치 관점 점수로 기업을 5가지 유형으로 분류했는데(예: 버핏 ≥ 4 & 린치 ≤ 1), 이것도 학습된 모델이 아니라 기준값 규칙이다. 로지스틱 회귀를 쓴 기록은 없다.

### 먼저 알면 좋은 것
- 회귀분석 기초(STAT-REG-001): 직선으로 점수 계산
- 지수와 로그(MATH-BASE-002): $e^x$와 $\ln$
- 확률, 조건부확률, 확률분포(STAT-PROB-001)

## 1. 핵심 요약

- **모델:** $p = \sigma(z) = \dfrac{1}{1 + e^{-z}}$, $z = b + w_1 x_1 + \dots + w_n x_n$.
- **오즈와 로그 오즈:** 오즈 $= p / (1 - p)$, 로그 오즈 $= \ln\frac{p}{1-p} = z$. 로그 오즈가 입력의 직선 함수다.
- **계수 해석:** $x_j$가 1 늘면 오즈가 $e^{w_j}$배(오즈비). 확률이 일정하게 늘어나는 것은 아니다.
- **학습:** 로그 손실(교차 엔트로피)을 최소화. 최대우도 추정과 같다. 닫힌 해가 없어 경사하강법이나 뉴턴법으로 푼다.
- **판정:** 기준값(임계값)으로 확률을 예/아니오로 바꾼다. 기준값은 오류 비용으로 정한다.
- **위치:** 신경망의 뉴런 하나(시그모이드)와 같은 구조이고, 분류 문제의 기준 모델로 가장 먼저 시도한다(신경망과 역전파, AI-NN-001).

## 2. 개념과 등장 배경

S자 곡선(로지스틱 함수)은 1830~40년대 벨기에의 수학자 페르휠스트(Verhulst)가 인구 증가 모형으로 처음 제안했다. 처음엔 빠르게 늘다가 한계에 가까워지면 느려지는 모양이다. 1958년 데이비드 콕스(David Cox)가 예/아니오 결과를 설명하는 회귀 방법으로 로지스틱 회귀를 정리했고, 이후 의학(질병 위험 요인), 신용평가(부도 확률), 마케팅(구매 확률)의 표준 도구가 되었다.

머신러닝에서도 로지스틱 회귀는 **기준 모델**로 쓰인다. 복잡한 모델(의사결정나무 앙상블, 신경망)이 로지스틱 회귀보다 의미 있게 나은지 먼저 확인하는 것이 좋은 관행이다.

## 3. 직관적 설명 및 기초 이론

### 확률, 오즈, 로그 오즈

| 확률 $p$ | 오즈 $p/(1-p)$ | 로그 오즈 $\ln$ 오즈 |
|---|---|---|
| 0.1 | 1/9 ≈ 0.111 | −2.197 |
| 0.5 | 1 | 0 |
| 0.8 | 4 | 1.386 |
| 0.9 | 9 | 2.197 |

**오즈**는 "될 가능성 대 안 될 가능성"이다. 확률 0.8이면 4 대 1. 확률은 0~1에 갇혀 있지만 로그 오즈는 −∞~+∞ 범위라, 직선(아무 값이나 나오는 점수)과 연결하기 좋다. 로지스틱 회귀는 "로그 오즈를 직선으로 예측"하는 모델이다.

### 시그모이드의 모양

$z$가 0 근처일 때는 확률이 빠르게 변하고, $z$가 크거나 작아지면 1이나 0에 가까워지며 거의 변하지 않는다. 그래서 같은 계수라도 **확률이 50% 근처일 때 입력 변화의 영향이 가장 크다**.

## 4. 엄밀한 정의와 작동 원리

### 모델

$$
P(y = 1 \mid \mathbf{x}) = \sigma(b + \mathbf{w}^\top \mathbf{x}),\qquad \sigma(z) = \frac{1}{1 + e^{-z}},\qquad \ln\frac{p}{1-p} = b + \mathbf{w}^\top \mathbf{x}
$$

### 손실과 최대우도

관측 $y_i \in \{0, 1\}$, 예측 $p_i$에 대해 데이터 전체의 가능도는 $\prod_i p_i^{y_i}(1-p_i)^{1-y_i}$이다. 로그를 취해 부호를 바꾸고 평균 내면 **로그 손실**:

$$
L = -\frac{1}{n}\sum_{i=1}^{n}\big[y_i \ln p_i + (1 - y_i)\ln(1 - p_i)\big]
$$

정답이 1인데 $p = 0.9$로 예측하면 손실 $-\ln 0.9 \approx 0.105$, $p = 0.1$로 자신 있게 틀리면 $-\ln 0.1 \approx 2.303$으로 크게 벌을 받는다.

### 기울기

$\partial L / \partial w_j = \frac{1}{n}\sum_i (p_i - y_i)\, x_{ij}$. 신경망의 출력층 오차 신호 $\hat{y} - y$와 같다(AI-NN-001). 손실이 볼록 함수라 지역 최솟값이 없고, 경사하강법이 전역 최솟값으로 간다(MATH-CALC-001). 데이터가 완벽히 나뉘면(분리 가능) 계수가 무한히 커지려 해서 규제가 필요하다(과적합과 교차검증, AI-VAL-001).

### 왜 제곱 오차가 아닌가

시그모이드 출력에 제곱 오차를 쓰면 손실이 볼록하지 않아 학습이 나쁜 지점에 갇힐 수 있고, 크게 틀린 예측에서 기울기가 작아져 학습이 느리다. 로그 손실은 확률 모형의 최대우도에서 자연스럽게 나오고 두 문제가 없다.

## 5. 수식 및 기호 설명

| 기호 | 읽기 | 뜻 |
|---|---|---|
| $p$ | 피 | $y = 1$일 확률 |
| $\sigma(z)$ | 시그모이드 | $1/(1+e^{-z})$ |
| $z$ | 제트 | 점수 = 로그 오즈 |
| $p/(1-p)$ | 오즈 | 될 가능성 대 안 될 가능성 |
| $e^{w}$ | 오즈비 | 입력 1 증가 시 오즈의 배수 |
| $L$ | 로그 손실 | 교차 엔트로피 |
| $t$ | 임계값 | $p \ge t$이면 1로 판정 |

## 6. 단계별 계산 또는 동작 예제

### 예제 1. 공부 시간과 합격

| 공부 시간 $x$ | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|
| 합격 $y$ | 0 | 0 | 1 | 0 | 1 | 1 |

최대우도로 맞추면 $b \approx -4.249$, $w \approx 1.214$다.

1. $x = 4$일 때 점수 $z = -4.249 + 1.214 \times 4 = 0.607$, 확률 $\sigma(0.607) \approx 0.647$.
2. 확률 50%가 되는 공부 시간: $z = 0 \Rightarrow x = 4.249 / 1.214 = 3.5$시간.
3. 오즈비: $e^{1.214} \approx 3.37$. 공부 1시간마다 합격 오즈가 약 3.4배.
4. 각 시간의 예측 확률: 0.046, 0.139, 0.353, 0.647, 0.861, 0.954.
5. 평균 로그 손실: 약 0.413. 아무 정보 없이 모두 0.5로 예측하면 $\ln 2 \approx 0.693$이다.

### 예제 2. 오즈비 해석의 함정

$w = 0.7$이면 오즈비 $e^{0.7} \approx 2.01$로 "오즈가 약 2배"다. 하지만 확률이 2배가 되는 것은 아니다. 확률 0.5(오즈 1)는 오즈 2인 확률 0.667로, 확률 0.9(오즈 9)는 오즈 18인 확률 0.947로 바뀐다. 확률이 이미 높으면 늘어나는 폭이 작다.

### 직접 해보기

기울기와 기준점을 직접 바꿔 로그 손실이 가장 작아지는 곳을 찾아보자. 최적값은 기울기 약 1.21, 기준점 약 −4.25(손실 0.4130)다.

```runjs
// @title 로지스틱 회귀: 기울기와 기준점을 바꿔 로그 손실 줄이기
// @label 평균 로그 손실
// @param w | 기울기(공부 1시간의 점수) | 0 | 2 | 1.2 | 0.1
// @param b | 기준점 | -6 | 0 | -4 | 0.5
// @expect w=1.2, b=-4 => 0.4157
// @expect w=0, b=0 => 0.6931
// @expect w=1, b=-3 => 0.437
const xs = [1, 2, 3, 4, 5, 6];
const ys = [0, 0, 1, 0, 1, 1];
const sig = (z) => 1 / (1 + Math.exp(-z));
let loss = 0;
const rows = xs.map((x, i) => {
  const z = b + w * x, p = sig(z);
  const l = -(ys[i] * Math.log(p) + (1 - ys[i]) * Math.log(1 - p));
  loss += l;
  return [x, ys[i], z.toFixed(2), p.toFixed(3), l.toFixed(3)];
});
loss /= xs.length;
table(rows, ['공부 시간', '합격', '점수 z', '확률 p', '손실']);
bars(xs.map((x) => x + '시간'), xs.map((x) => Number(sig(b + w * x).toFixed(3))));
if (w > 0) log('확률 50%가 되는 공부 시간 =', (-b / w).toFixed(2), '시간 / 오즈비 e^w =', Math.exp(w).toFixed(2));
result(Math.round(loss * 1e4) / 1e4);
```

### 예제 3. 임계값에 따른 판정

예제 1의 확률에 임계값 0.5를 쓰면 4시간(0.647)은 합격으로 판정되지만 실제로는 불합격이라 거짓 양성 1건, 3시간(0.353)은 불합격 판정인데 실제로는 합격이라 거짓 음성 1건이다. 임계값을 0.3으로 내리면 3시간도 합격으로 판정되어 거짓 음성은 0건, 거짓 양성은 4시간 1건(2시간 0.139는 여전히 불합격)이다. 어느 쪽이 나은지는 두 오류의 비용으로 정한다(AI-EVAL-001).

## 7. 시각화와 해석

가로축 입력, 세로축 확률로 S자 곡선과 실제 0/1 점을 함께 그리면 모델이 어디서 확신하고 어디서 망설이는지 보인다. 예측 확률이 믿을 만한지는 **보정 곡선**(calibration curve)으로 확인한다. 예측 확률을 구간(0~0.1, 0.1~0.2, …)으로 묶어, 각 구간에서 실제로 1이었던 비율을 점으로 찍는다. 대각선 위에 있으면 "70%라고 한 것이 실제로 70% 맞는다"는 뜻이다. 임계값 선택에는 ROC 곡선과 정밀도-재현율 곡선을 쓴다.

| 모델 | 장점 | 단점 | 맞는 경우 |
|---|---|---|---|
| 로지스틱 회귀 | 해석 쉬움, 확률이 비교적 잘 보정됨, 빠름 | 입력과 로그 오즈의 직선 관계만 | 기준 모델, 설명이 필요한 판정(신용, 의료) |
| 의사결정나무 앙상블(AI-TREE-001) | 비선형·상호작용 자동, 표 데이터에 강함 | 해석 어려움, 확률 보정 필요할 때 많음 | 성능이 중요한 표 데이터 |
| 신경망(AI-NN-001) | 이미지·텍스트·음성 | 데이터·계산 많이 필요 | 비정형 데이터 |
| 규칙(SE-RULE-001) | 완전한 통제와 설명 | 데이터로 배우지 않음 | 업무 규칙이 명확할 때 |

여러 클래스(3개 이상)는 소프트맥스를 쓰는 **다항 로지스틱 회귀**로 확장한다. LLM의 다음 토큰 확률 계산이 이 구조의 거대한 버전이다(AI-LLM-001).

## 9. 실무 사례

- **신용평가:** 부도 확률을 로지스틱 회귀로 계산하고 계수를 점수표로 바꿔, 왜 이 점수가 나왔는지 설명한다. 규제가 설명 가능성을 요구하는 분야에서 여전히 표준이다.
- **이탈 예측:** 고객이 다음 달 떠날 확률을 계산해 상위 고객부터 관리한다. 확률 순위만 쓰는 경우 보정보다 순위 품질(AUC)이 중요하다.
- **A/B 테스트 분석:** 전환 여부(0/1)를 결과로, 실험 집단을 입력으로 넣어 효과를 오즈비로 추정하고 다른 변수를 통제한다(인과 추론과 실험 설계, STAT-CAUSAL-001).
- **LLM 판정 보정:** LLM이 내는 점수나 판정을 사람 라벨에 맞춰 확률로 바꾸는 데 로지스틱 회귀(Platt 보정)를 쓴다.

## 10. 기존 프로젝트와의 연결

아래 사실은 포트폴리오·저장소 원문(`content/profile.json`)에서 옮긴 것이다.

- **STT — SemWER@0.85의 기준값:** 의미 유사도 0.85 이상을 "의미 보존"으로 봤고, 선택 이유는 기재되어 있지 않다. 점검 질문: 문장 수백 개에 사람이 "의미 보존됨/아님"을 표시하면, 유사도를 입력으로 하는 로지스틱 회귀를 맞춰 "사람이 보존됐다고 볼 확률 50%(또는 원하는 재현율)"에 해당하는 유사도를 기준값으로 정할 수 있다. 그러면 0.85가 근거를 갖거나 다른 값으로 바뀐다.
- **Preflight — 규칙 판정과 데이터:** 위험한 변경을 검토 대기열로 보내는 판정은 규칙이다. 점검 질문: 검토자가 실제로 "문제 있음"으로 처리한 기록이 쌓이면, 어떤 칸 변경이 문제로 이어지는지 로지스틱 회귀로 분석해 규칙을 다듬는 근거로 쓸 수 있다. 판정 자체를 모델로 바꾸기보다 규칙 개선의 근거로 쓰는 편이 Preflight의 "업무 규칙은 정책으로 분리" 구조와 맞다.
- **DeepVi — 유형 분류:** 버핏 ≥ 4 & 린치 ≤ 1 같은 기준값 규칙으로 분류했다. 학습할 정답(예: 이후 실제 수익률 구간)이 없으면 로지스틱 회귀를 쓸 수 없다. 규칙 기반 분류가 맞는 선택이다.

## 11. 가정·한계·흔한 오해·트레이드오프

- **오해: 이름이 회귀라서 수치 예측 모델이다.** 분류 모델이다. 로그 오즈를 회귀하기 때문에 이름이 이렇다.
- **오해: 계수가 크면 확률이 그만큼 커진다.** 계수는 로그 오즈 단위다. 확률 변화는 현재 확률 수준에 따라 다르다(예제 2).
- **직선 가정:** 입력과 로그 오즈의 관계가 곡선이면 맞지 않는다. 구간 나누기, 변환(로그), 상호작용 항으로 보완한다.
- **상관이 높은 입력:** 계수가 불안정해져 해석이 흔들린다(STAT-REG-001).
- **불균형 데이터:** 양성이 1%면 모두 음성으로 예측해도 정확도 99%다. 정밀도·재현율로 평가하고 임계값을 조정한다(AI-EVAL-001).
- **인과 아님:** 계수는 연관의 크기이고, 무작위 실험이 아니면 원인의 효과로 해석할 수 없다(STAT-CAUSAL-001).

## 12. 이해 확인 및 면접 질문

<details class="qa" data-type="concept"><summary>Q1. 확률 0.75의 오즈와 로그 오즈는?</summary>

**정답.** 오즈 $0.75 / 0.25 = 3$, 로그 오즈 $\ln 3 \approx 1.099$.

**해설.** 오즈 3은 "될 가능성이 안 될 가능성의 3배"라는 뜻이다.

</details>

<details class="qa" data-type="concept"><summary>Q2. 계수 w = −0.5인 입력이 1 늘면 오즈는 어떻게 되는가?</summary>

**정답.** $e^{-0.5} \approx 0.607$배가 된다. 즉 오즈가 약 39% 줄어든다.

**해설.** 음수 계수는 오즈비가 1보다 작아 가능성을 낮춘다.

</details>

<details class="qa" data-type="judgment"><summary>Q3. 로지스틱 회귀의 검증 세트 AUC가 0.81, 그래디언트 부스팅이 0.82다. 금융 심사 업무에 어느 쪽을 쓰겠는가?</summary>

**정답.** 차이가 교차검증의 흔들림 안이라면 로지스틱 회귀를 쓴다. 심사 결과를 신청자와 감독기관에 설명해야 하고, 계수로 영향을 보여 줄 수 있으며, 운영·감사가 쉽다. 차이가 꾸준하고 크거나 설명 요구가 낮다면 부스팅을 쓰되 설명 도구와 보정을 함께 둔다.

**해설.** 성능 차이의 크기와 불확실성, 설명 요구, 운영 비용을 함께 보는 판단이다(AI-VAL-001).

</details>

<details class="qa" data-type="applied"><summary>Q4. 의미 유사도 점수로 "의미 보존 여부"를 판정하는 기준값을 정해야 한다. 데이터로 어떻게 정하겠는가?</summary>

**정답.** 대표 표본 수백 쌍에 사람이 보존 여부를 라벨링하고, 유사도를 입력으로 로지스틱 회귀를 맞춘다. 원하는 운영 목표(예: 의미 훼손을 90% 이상 잡기)에 맞는 확률 기준을 정해 유사도 값으로 환산하고, 따로 떼어 둔 표본으로 정밀도·재현율을 확인한다. 라벨러 간 일치도도 함께 본다.

**해설.** 기준값을 감으로 정하지 않고 사람 판단과 연결해 근거를 남긴다.

</details>
