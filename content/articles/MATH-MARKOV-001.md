## 0. 한눈에 보기 (입문)

### 한 줄 요약
**마르코프 연쇄**는 "다음에 어떤 상태가 될지가 지금 상태에만 달려 있는" 확률적 상태 변화 모형이다. 상태 머신(CS-GEN-001)의 화살표에 **확률**을 붙인 것이라고 생각하면 된다.

### 쉬운 설명
날씨를 아주 단순하게 생각해 보자.

- 오늘 맑으면 내일도 맑을 확률 90%, 비 올 확률 10%.
- 오늘 비가 오면 내일 맑을 확률 50%, 또 비 올 확률 50%.

내일 날씨는 **오늘 날씨만** 보면 된다. 어제, 그저께 날씨는 상관없다고 가정한다. 이것이 마르코프 성질이다.

이 규칙으로 계산하면 "오늘 맑음 → 모레 맑을 확률"도 구할 수 있고, 아주 오래 지나면 "전체 날 중 맑은 날의 비율"이 일정한 값(약 83%)에 가까워진다는 것도 알 수 있다. 처음이 맑았든 비가 왔든 상관없이. 이 값이 **정상 분포**다.

### 내 프로젝트에서는
- **Preflight의 업무 단계는 상태 머신이고, 확률을 붙이면 마르코프 연쇄가 된다.** 업무 행은 진행 중·완료·취소·드롭 같은 단계를 오간다(ADR-05, 포트폴리오 기재). 과거 이력에서 "진행 중인 업무가 한 주 뒤 완료될 비율" 같은 전이 확률을 세면, 미결 업무가 몇 주 뒤 얼마나 남을지 예측할 수 있다(6절 예제 2, 적용 아이디어).
- **이 학습 사이트의 간격 반복 복습이 상자 사이를 오가는 연쇄다.** 문항 카드는 상자 0~4에 있고, "맞힘"이면 다음 상자(복습 간격 1·3·7·21·60일), "헷갈림"이면 그대로, "틀림"이면 상자 0으로 간다(`src/core.js`의 `gradeCard`). 채점 결과의 확률이 상자에만 달려 있다고 가정하면 마르코프 연쇄로 분석할 수 있다(6절 예제 3).
- **DeepVi가 쓴 GPT-4o 같은 언어 모델은 "다음 토큰 확률"을 계산한다.** 고전적인 n-gram 언어 모델은 앞의 몇 단어만 보는 마르코프 연쇄였고, 트랜스포머는 훨씬 긴 문맥을 보도록 확장한 것이다(AI-LLM-001).

## 1. 핵심 요약

- **마르코프 성질:** $P(X_{t+1} \mid X_t, X_{t-1}, \dots) = P(X_{t+1} \mid X_t)$. 미래는 현재만으로 정해진다(과거는 현재에 이미 반영되었다고 가정).
- **전이 행렬 $P$:** $P_{ij}$ = 상태 $i$에서 $j$로 갈 확률. 각 행의 합 = 1.
- **분포 갱신:** 행 벡터 $\pi_t$에 대해 $\pi_{t+1} = \pi_t P$, $n$단계 뒤 $\pi_{t+n} = \pi_t P^n$.
- **정상 분포:** $\pi = \pi P$를 만족하는 분포. 조건(모든 상태끼리 오갈 수 있고 주기가 없음)을 만족하면 어디서 시작하든 여기로 수렴한다.
- **흡수 연쇄:** 끝나는 상태가 있으면 "어느 끝에 도착할 확률", "도착까지 평균 단계 수"를 계산할 수 있다.
- **쓰임:** 업무 흐름 예측, 고객 이탈, 대기열, PageRank, 간격 반복, n-gram 언어 모델, MCMC(베이즈 계산, STAT-BAYES-001).

## 2. 개념과 등장 배경

1906년 러시아 수학자 안드레이 마르코프(Andrey Markov)가 독립이 아닌 확률 변수의 연쇄에서도 큰 수의 법칙이 성립함을 보이려고 이 모형을 연구했다. 1913년에는 푸시킨의 시 『예브게니 오네긴』의 글자 2만 개를 세어 모음·자음이 이어지는 확률을 계산했는데, 이것이 언어에 확률 모형을 적용한 초기 사례로 꼽힌다. 1948년 섀넌은 이 아이디어로 글자·단어를 확률적으로 생성해 보이며 정보 이론을 세웠다(MATH-INFO-001).

이후 마르코프 연쇄는 대기열 이론, 유전학, 금융, 물리에서 표준 도구가 되었다. 1998년 구글의 브린(Brin)과 페이지(Page)는 "무작위로 링크를 따라 웹을 떠도는 사람"의 정상 분포로 페이지 중요도를 매기는 **PageRank**를 발표했다. 1990년대 이후에는 마르코프 연쇄를 이용해 복잡한 확률 분포에서 표본을 뽑는 MCMC가 베이즈 통계의 계산을 가능하게 했다.

## 3. 직관적 설명 및 기초 이론

### 상태 그림 = 확률이 붙은 상태 머신

```text
        0.9            0.5
      ┌────┐        ┌────┐
      ▼    │        ▼    │
     맑음 ──0.1──▶  비
      ▲            │
      └────0.5─────┘
```

각 상태에서 나가는 화살표의 확률 합이 1이다. 상태 머신(CS-GEN-001)이 "이벤트가 오면 어디로 가는가"라면, 마르코프 연쇄는 "어디로 갈 확률이 얼마인가"다. 그래프 관점에서는 가중치가 확률인 방향 그래프다(MATH-GRAPH-001).

### 마르코프 가정은 근사다

실제 날씨는 며칠 전 날씨와 계절에도 영향을 받는다. 그래도 "현재 상태"를 잘 정의하면(예: 상태에 계절을 포함) 마르코프 가정이 더 잘 맞는다. 업무 흐름에서도 "진행 중"을 "진행 중(1주차)", "진행 중(2주 이상)"으로 나누면 오래 걸리는 업무의 특성을 반영할 수 있다.

## 4. 엄밀한 정의와 작동 원리

### 전이 행렬과 분포

상태 $\{1, \dots, m\}$, 전이 행렬 $P$($m \times m$, 각 행의 합 1). 지금 상태 분포가 행 벡터 $\pi_t$이면

$$
\pi_{t+1} = \pi_t P, \qquad \pi_{t+n} = \pi_t P^n
$$

행렬 곱(MATH-LA-002)으로 계산한다. $(P^n)_{ij}$는 $i$에서 시작해 정확히 $n$단계 뒤 $j$에 있을 확률이다.

### 정상 분포

$$
\pi = \pi P, \qquad \sum_i \pi_i = 1
$$

2상태(맑음 S, 비 R)에서 $P_{SR} = a$, $P_{RS} = b$이면 들어오는 흐름과 나가는 흐름이 같아야 하므로 $\pi_S a = \pi_R b$, 따라서

$$
\pi_S = \frac{b}{a + b}, \qquad \pi_R = \frac{a}{a + b}
$$

선형대수로는 $P$의 고유값 1에 대한 왼쪽 고유벡터다(MATH-LA-003의 고유벡터).

### 흡수 연쇄

상태가 "지나가는 상태"와 "흡수 상태"로 나뉘면, 지나가는 상태끼리의 전이 행렬 $Q$로 **기본 행렬** $N = (I - Q)^{-1}$을 만든다. $N$의 행 합은 흡수될 때까지의 평균 단계 수다. 지나가는 상태가 하나이고 머무를 확률이 $q$면 평균 단계 수는 $1/(1 - q)$(기하분포의 평균)다.

## 5. 수식 및 기호 설명

| 기호 | 뜻 |
|---|---|
| $X_t$ | 시점 $t$의 상태 |
| $P_{ij}$ | 상태 $i$에서 $j$로 갈 확률 |
| $\pi_t$ | 시점 $t$의 상태 분포(행 벡터) |
| $P^n$ | $n$단계 전이 행렬 |
| $\pi = \pi P$ | 정상 분포의 조건 |
| $N = (I - Q)^{-1}$ | 흡수 연쇄의 기본 행렬 |

## 6. 단계별 계산 또는 동작 예제

### 예제 1. 날씨 연쇄

$$
P = \begin{pmatrix} 0.9 & 0.1 \\ 0.5 & 0.5 \end{pmatrix} \quad (\text{행: 오늘 맑음, 비 / 열: 내일 맑음, 비})
$$

오늘 맑음 $\pi_0 = (1, 0)$:
- 1일 뒤: $(0.9,\ 0.1)$
- 2일 뒤: $(0.9 \times 0.9 + 0.1 \times 0.5,\ 0.9 \times 0.1 + 0.1 \times 0.5) = (0.86,\ 0.14)$
- 3일 뒤: $(0.844,\ 0.156)$

정상 분포: $a = 0.1$, $b = 0.5$ → $\pi_S = 0.5 / 0.6 \approx 0.833$, $\pi_R \approx 0.167$. 3일 만에 이미 0.844로 가까워졌다. 비 오는 날에서 시작해도 같은 값으로 수렴한다.

### 예제 2. 업무 단계 예측 (설명용 확률)

과거 이력에서 "진행 중" 업무가 한 주 뒤 진행 중 0.70, 완료 0.25, 취소 0.05였고, 완료·취소는 흡수 상태라고 하자.

| 주 | 진행 중 | 완료 | 취소 |
|---|---|---|---|
| 0 | 1 | 0 | 0 |
| 1 | 0.70 | 0.25 | 0.05 |
| 2 | 0.49 | 0.425 | 0.085 |
| 3 | 0.343 | 0.548 | 0.110 |
| 4 | 0.240 | 0.633 | 0.127 |

- 4주 뒤에도 약 24%가 미결로 남는다. 지금 미결 100건이면 4주 뒤 약 24건.
- 끝날 때까지 평균 $1 / (1 - 0.7) \approx 3.33$주.
- 결국 완료로 끝날 확률 $0.25 / (0.25 + 0.05) \approx 0.833$.

실제 Preflight에는 "완료 → 진행 중" 같은 역방향 전이가 있고(검토 대상), 업무 종류별로 확률이 다르므로, 이 예는 개념 설명용이다. 이력에서 전이를 셀 때는 Preflight처럼 이력을 지우지 않고 남기는 설계(ADR-05)가 전제다.

### 예제 3. 간격 반복 상자

이 사이트의 채점 규칙(맞힘 → 다음 상자, 헷갈림 → 그대로, 틀림 → 상자 0)에서, 어떤 학습자가 상자와 상관없이 맞힘 0.8, 헷갈림 0.1, 틀림 0.1이라고 가정하자. 상자 1에 있는 카드의 다음 상자 분포는 상자 2 0.8, 상자 1 0.1, 상자 0 0.1이다. 이 전이 행렬로 "카드가 상자 4(60일 간격)에 도달하기까지 평균 복습 횟수"를 계산할 수 있고, 틀림 확률이 클수록 상자 0으로 자주 돌아가 도달이 늦어진다. 실제로는 상자가 높을수록(오래 기억할수록) 맞힐 확률이 달라질 수 있어, 상자별 확률을 기록으로 추정하는 것이 정확하다.

## 7. 시각화와 해석

상태를 원, 전이 확률을 화살표 굵기로 그리면 흐름이 한눈에 보인다. 예제 2의 표를 누적 막대(주별 진행 중·완료·취소 비율)로 그리면 미결이 줄어드는 속도가 보인다. 정상 분포로 수렴하는 모습은 시작 상태가 다른 두 선(맑음 시작, 비 시작)이 같은 값으로 모여드는 그래프로 확인한다.

## 8. 기술 비교 및 선택 기준

| 상황 | 모형 |
|---|---|
| 상태가 몇 개, 전이가 현재에만 의존 | 마르코프 연쇄 |
| 과거 몇 단계가 중요 | 상태를 확장(최근 2단계를 상태로) 또는 고차 마르코프 |
| 상태를 직접 관찰 못 함(숨은 상태) | 은닉 마르코프 모형(HMM, 고전 음성 인식) |
| 상태에서 머무는 시간이 중요 | 생존 분석, 준마르코프 모형 |
| 의사결정이 전이에 개입 | 마르코프 결정 과정(강화학습) |
| 아주 긴 문맥에 의존(언어) | 트랜스포머(AI-LLM-001) |

## 9. 실무 사례

- **고객 이탈·생애 가치:** 활성 → 휴면 → 이탈 전이 확률로 미래 고객 수를 예측한다.
- **PageRank:** 웹 페이지 링크 그래프 위 무작위 이동의 정상 분포가 페이지 중요도다. 지식 그래프에서 중요한 엔터티를 찾는 데도 응용된다(KE-KGB-001).
- **대기열:** 대기 인원 수를 상태로 보면 큐 길이 변화를 분석할 수 있다(SE-QUEUE-001).
- **텍스트 생성(고전):** 앞 단어 하나·둘로 다음 단어를 고르는 n-gram 모형.

## 10. 기존 프로젝트와의 연결

아래 사실은 포트폴리오·저장소 원문(`content/profile.json`)과 이 사이트의 코드에서 옮긴 것이다.

- **Preflight — 업무 단계:** 진행 중·완료·취소·드롭 단계로 관리하고, 위험한 전이(완료 → 진행 중)는 검토로 보낸다. 이력이 남아 있으므로 업무 종류별 주간 전이 횟수를 세어 전이 확률을 추정하면, 미결 업무 예측(예제 2)과 "평소와 다른 전이 비율"(관리도, STAT-SPC-001) 감시에 쓸 수 있다(적용 아이디어).
- **이 학습 사이트 — 간격 반복:** `gradeCard`의 상자 규칙과 간격 [1, 3, 7, 21, 60]일. 저장된 채점 기록에서 상자별 맞힘 비율을 세면, 간격 설정이 학습자에게 맞는지 점검할 수 있다(예제 3).
- **DeepVi — 언어 모델:** GPT-4o(temperature 0.3)로 답을 생성했다. 다음 토큰 확률에서 하나씩 고르는 생성 과정은 "상태 = 지금까지의 문맥"인 확률적 연쇄로 볼 수 있다(AI-LLM-001, MATH-INFO-001).

## 11. 가정·한계·흔한 오해·트레이드오프

- **오해: 마르코프면 과거가 영향을 안 준다.** 과거가 현재 상태에 다 담겨 있다고 **가정**하는 것이다. 상태 정의가 부실하면 가정이 깨진다.
- **오해: 전이 확률은 고정이다.** 계절, 정책 변경으로 바뀐다. 기간별로 다시 추정한다(시간에 따라 변하는 연쇄).
- **표본 부족:** 드문 전이(완료 → 진행 중)는 확률 추정이 불안정하다. 신뢰구간이나 베이즈 사전(STAT-BAYES-001)으로 보완한다.
- **수렴 조건:** 서로 오갈 수 없는 상태 묶음이 있거나 주기가 있으면 정상 분포로 수렴하지 않을 수 있다.
- **해석:** 정상 분포는 "아주 오래 지난 뒤의 비율"이지 내일 확률이 아니다.

## 12. 이해 확인 및 면접 질문

<details class="qa" data-type="concept"><summary>Q1. 2상태 연쇄에서 A → B 확률 0.2, B → A 확률 0.3이다. 정상 분포는?</summary>

**정답.** $\pi_A = 0.3 / (0.2 + 0.3) = 0.6$, $\pi_B = 0.4$.

**해설.** 들어오는 흐름과 나가는 흐름이 같아야 한다: $\pi_A \times 0.2 = \pi_B \times 0.3$.

</details>

<details class="qa" data-type="concept"><summary>Q2. 한 주 뒤에도 진행 중으로 남을 확률이 0.8인 업무는 평균 몇 주 만에 끝나는가? (매주 독립 가정)</summary>

**정답.** $1 / (1 - 0.8) = 5$주.

**해설.** 매주 끝날 확률 0.2인 기하분포의 평균이다.

</details>

<details class="qa" data-type="judgment"><summary>Q3. 업무 이력으로 전이 확률을 추정해 다음 달 미결 건수를 예측하려 한다. 무엇을 주의하겠는가?</summary>

**정답.** 업무 종류·규모별로 전이 확률이 다를 수 있으니 나눠서 추정하고, 진행 기간이 길수록 끝날 확률이 달라지는지(마르코프 가정 위반) 확인한다. 최근 정책·인력 변화로 확률이 바뀌었는지 기간별로 비교하고, 드문 전이는 불확실성을 함께 보고한다.

**해설.** 모형의 가정(현재 상태만으로 충분, 확률 고정)을 데이터로 점검하는 것이 핵심이다.

</details>

<details class="qa" data-type="applied"><summary>Q4. 고객이 활성 → 휴면 0.1, 휴면 → 활성 0.3, 휴면 → 이탈 0.2(이탈은 흡수)이고 활성은 그 외 그대로, 휴면도 그 외 그대로다. 지금 활성 고객 1,000명이면 한 달 뒤 각 상태는 몇 명인가?</summary>

**정답.** 활성 900명, 휴면 100명, 이탈 0명.

**해설.** 한 단계만 지나면 활성에서 휴면으로만 이동한다(1,000 × 0.1). 두 달 뒤에는 휴면 100명 중 30명이 활성으로, 20명이 이탈로 이동해 활성 $900 \times 0.9 + 30 = 840$명, 휴면 $90 + 50 = 140$명, 이탈 20명이 된다.

</details>
