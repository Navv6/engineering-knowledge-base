## 0. 한눈에 보기 (입문)

### 한 줄 요약
**부트스트랩**은 가진 데이터에서 "다시 뽑기"를 수천 번 반복해, 평균 같은 숫자가 표본에 따라 얼마나 흔들릴지 재는 방법이다. 복잡한 공식 없이 컴퓨터 반복 계산만으로 신뢰구간을 얻는다. 비슷한 원리의 **순열 검정**은 두 집단의 차이가 우연인지 판단한다.

### 쉬운 설명
어떤 업무 처리 시간을 8번 재서 평균 15.75분이 나왔다. 다른 날 8번을 다시 재면 평균이 조금 달라질 것이다. 얼마나 달라질까? 정석은 여러 날 다시 재 보는 것이지만, 그럴 시간이 없다.

부트스트랩의 아이디어: **가진 8개를 "모집단의 축소판"으로 보고, 여기서 다시 뽑아 본다.**
1. 8개 값이 적힌 쪽지를 주머니에 넣는다.
2. 하나 뽑아 적고 **다시 넣는다**(복원 추출). 이걸 8번 해서 새 표본을 만든다. 같은 쪽지가 두 번 나올 수도, 한 번도 안 나올 수도 있다.
3. 새 표본의 평균을 계산한다.
4. 2~3을 수천 번 반복하면 평균이 수천 개 생긴다. 이 평균들이 퍼진 정도가 "표본에 따라 평균이 흔들리는 정도"의 추정이다.
5. 수천 개 평균을 작은 순서로 줄 세워 가운데 95%를 잘라내면 95% 신뢰구간이 된다.

**순열 검정**은 이렇게 생각한다. "새 방식"과 "옛 방식"의 처리 시간 차이가 3.75분이다. 만약 방식이 아무 효과가 없다면, 어떤 값이 어느 쪽에 속했는지는 우연일 뿐이다. 그래서 이름표를 무작위로 섞어 차이를 다시 계산해 보고, 3.75분 이상 차이가 날 만큼 섞이는 경우가 얼마나 드문지 센다. 드물면 "우연이라고 보기 어렵다"고 판단한다.

### 내 프로젝트에서는
- **STT 평가 — 모델 간 작은 차이:** NeMo Conformer CTC WER 0.226, Whisper-small-ko Fine-tuned WER 0.239로 차이가 0.013이다. 의미 유사도는 Whisper 0.917, NeMo 0.934였다(포트폴리오 기재). 같은 6,000개 문장에 두 모델을 적용했으므로, **문장을 단위로 부트스트랩**하면(문장을 복원 추출해 두 모델의 WER 차이를 다시 계산) 이 차이의 신뢰구간을 얻을 수 있다. 구간이 0을 포함하지 않으면 차이가 우연이 아니라고 말할 수 있다. 포트폴리오에는 이런 불확실성 계산이 기재되어 있지 않아 점검 사항으로 남긴다(10절).
- **Preflight:** 샘플창고 개선은 정성 비교로 기록되어 있다(포트폴리오 기재). 수치 비교를 하게 되면, 도입 전후 처리 시간의 차이를 순열 검정으로 확인할 수 있다(단, 전후 비교의 한계는 STAT-CAUSAL-001 참고).
- **DeepVi:** 부트스트랩이나 순열 검정을 쓴 기록은 없다.

### 먼저 알면 좋은 것
- 모집단, 표본, 추정, 신뢰구간(STAT-INF-001): 표준오차와 신뢰구간의 뜻
- 가설검정과 p-value(STAT-INF-002): 귀무가설과 p-value

## 1. 핵심 요약

- **아이디어:** 모집단 대신 표본의 경험적 분포에서 다시 뽑아, 추정량의 표본 분포를 근사한다.
- **절차:** 크기 $n$의 표본에서 $n$개를 복원 추출 → 통계량 계산 → $B$번(보통 1,000~10,000) 반복.
- **결과물:** 부트스트랩 표준오차(반복값들의 표준편차), 백분위수 신뢰구간(반복값의 2.5%·97.5% 지점).
- **장점:** 중앙값, 비율의 비, 상관계수, 모델 성능 지표처럼 공식이 없거나 복잡한 통계량에도 쓴다.
- **순열 검정:** 귀무가설(효과 없음) 아래에서 집단 이름표를 섞어 차이의 분포를 만들고 p-value를 계산. 분포 가정이 거의 없다.
- **주의:** 표본이 아주 작거나, 데이터가 서로 의존(시계열, 같은 사람의 여러 값)하거나, 최댓값 같은 극단 통계량에는 그대로 쓰면 틀린다.

## 2. 개념과 등장 배경

1935년 로널드 피셔는 *The Design of Experiments*에서 차를 맛보는 여인 실험을 예로 들며, 가능한 모든 배정을 따져 우연의 확률을 계산하는 **무작위화 검정(순열 검정)**의 원리를 보였다. 계산량이 너무 많아 오랫동안 이론적 기준으로만 쓰였다.

1979년 브래들리 에프론(Bradley Efron)이 **부트스트랩**을 발표했다. 이름은 "자기 구두끈(bootstrap)을 당겨 스스로를 들어 올린다"는 영어 표현에서 왔다. 가진 데이터만으로 그 데이터의 불확실성을 잰다는 뜻이다. 컴퓨터가 빨라지면서 두 방법 모두 실용적인 표준 도구가 되었고, 에프론은 이 공로로 2018년 11월 발표된 첫 국제통계상(International Prize in Statistics) 수상자가 되었다.

## 3. 직관적 설명 및 기초 이론

### "표본이 모집단을 대신한다"

추정의 흔들림을 알려면 원래는 모집단에서 표본을 여러 번 뽑아 봐야 한다. 부트스트랩은 모집단 대신 **표본 자체를 모집단으로 보고** 같은 일을 한다. 표본이 모집단을 잘 닮았다면(충분히 크고 무작위로 뽑혔다면), 표본에서 다시 뽑은 결과의 흔들림이 모집단에서 뽑은 결과의 흔들림과 비슷하다.

### 한 번도 안 뽑히는 값

복원 추출로 $n$개를 뽑을 때 특정 값이 한 번도 안 뽑힐 확률은 $(1 - 1/n)^n$이고, $n$이 크면 $e^{-1} \approx 0.368$에 가까워진다. 즉 각 부트스트랩 표본은 원래 값의 약 63%만 포함한다(지수와 로그, MATH-BASE-002). 의사결정나무 앙상블의 배깅(랜덤 포레스트)이 이 성질을 쓴다(AI-TREE-001).

### 순열 검정의 논리

귀무가설이 "두 방식은 차이가 없다"라면, 각 값에 붙은 "새 방식/옛 방식" 이름표는 결과와 무관하게 붙은 것이다. 그러면 이름표를 어떻게 바꿔 붙여도 똑같이 그럴듯한 데이터다. 가능한 모든 이름표 배치에서 차이를 계산하면 "효과가 없을 때 나올 수 있는 차이의 분포"가 정확히 만들어진다. 실제 차이가 이 분포의 끝에 있으면 귀무가설과 맞지 않는다.

## 4. 엄밀한 정의와 작동 원리

### 부트스트랩

표본 $x_1, \dots, x_n$의 경험적 분포 $\hat{F}_n$(각 값에 확률 $1/n$)에서 $x^*_1, \dots, x^*_n$을 독립적으로 뽑아 통계량 $\hat{\theta}^* = s(x^*)$를 계산하고, 이를 $B$번 반복해 $\hat{\theta}^*_1, \dots, \hat{\theta}^*_B$를 얻는다.

$$
\widehat{\text{SE}}_{\text{boot}} = \sqrt{\frac{1}{B-1}\sum_{b=1}^{B}\big(\hat{\theta}^*_b - \bar{\theta}^*\big)^2}
$$

**백분위수 구간:** $\hat{\theta}^*$들의 $\alpha/2$, $1 - \alpha/2$ 분위수. 치우침과 비대칭을 보정한 **BCa 구간**이 더 정확한 경우가 많다.

### 순열 검정

두 집단 크기 $n_A$, $n_B$, 검정 통계량 $T$(예: 평균 차이). 합친 $n = n_A + n_B$개 값을 $n_A$개와 $n_B$개로 나누는 $\binom{n}{n_A}$가지 배치마다 $T$를 계산해, 양측 p-value를

$$
p = \frac{\#\{\text{배치}: |T_{\text{배치}}| \ge |T_{\text{관측}}|\}}{\binom{n}{n_A}}
$$

로 구한다. 배치 수가 너무 많으면 무작위로 수천~수만 번만 섞어 근사한다(경우의 수와 조합, MATH-COMB-001).

### 짝지은 데이터

같은 대상에 두 처리를 모두 적용했다면(같은 문장에 두 모델) **대상 단위로** 다시 뽑거나, 대상마다 두 값의 차이를 구한 뒤 그 차이의 부호를 무작위로 바꾸는 검정을 한다. 대상을 무시하고 값을 따로 섞으면 짝의 정보를 버려 검정력이 떨어진다.

## 5. 수식 및 기호 설명

| 기호 | 읽기 | 뜻 |
|---|---|---|
| $\hat{F}_n$ | 에프 햇 엔 | 경험적 분포(표본의 각 값에 $1/n$) |
| $x^*$ | 엑스 스타 | 부트스트랩 표본(복원 추출) |
| $\hat{\theta}^*_b$ | 세타 햇 스타 | $b$번째 부트스트랩 통계량 |
| $B$ | 비 | 반복 횟수 |
| $\widehat{\text{SE}}_{\text{boot}}$ | | 부트스트랩 표준오차 |
| $\binom{n}{k}$ | 엔 씨 케이 | $n$개에서 $k$개를 고르는 경우의 수 |

## 6. 단계별 계산 또는 동작 예제

### 예제 1. 처리 시간 평균의 부트스트랩 구간

처리 시간(분, 설명용): 12, 15, 9, 22, 14, 30, 11, 13. 평균 15.75, 중앙값 13.5.

부트스트랩 표본 하나의 예: 15, 30, 11, 15, 9, 13, 30, 22 → 평균 18.125. 30이 두 번, 12와 14는 한 번도 안 뽑혔다.

2,000번 반복(시드 1)한 결과:
- 부트스트랩 표준오차 약 2.33. 공식 $s/\sqrt{n} = 6.92/\sqrt{8} \approx 2.45$와 비슷하다.
- 95% 백분위수 구간: **11.75 ~ 20.75**분. 평균 15.75를 중심으로 위쪽이 더 길다(5.0 vs 4.0). 30분 같은 큰 값이 뽑힐 때 평균이 크게 올라가는 비대칭이 드러난다.
- t분포 공식 구간은 9.96 ~ 21.54로 대칭이고 더 넓다. 표본이 8개뿐이라 부트스트랩 구간은 흔들림을 **작게** 추정하는 경향이 있다(11절).

### 직접 해보기

반복 횟수, 시드, 통계량(평균·중앙값)을 바꿔 보자. 시드를 바꾸면 구간 끝이 조금씩 달라진다. 반복이 많을수록 덜 흔들린다.

```runjs
// @title 부트스트랩: 다시 뽑기로 신뢰구간 만들기
// @label 95% 구간의 아래쪽 끝(분)
// @param B | 반복 횟수 | 200 | 5000 | 2000 | 200
// @param seed | 난수 시드 | 1 | 10 | 1 | 1
// @param useMedian | 통계량(0 = 평균, 1 = 중앙값) | 0 | 1 | 0 | 1
// @expect B=2000, seed=1, useMedian=0 => 11.75
// @expect B=2000, seed=2, useMedian=0 => 11.88
// @expect B=2000, seed=1, useMedian=1 => 11
const data = [12, 15, 9, 22, 14, 30, 11, 13];   // 처리 시간(분), 설명용
let a = seed;                                   // 시드 고정 난수(mulberry32)
const rand = () => { a |= 0; a = (a + 0x6D2B79F5) | 0; let t = Math.imul(a ^ (a >>> 15), 1 | a); t = (t + Math.imul(t ^ (t >>> 7), 61 | t)) ^ t; return ((t ^ (t >>> 14)) >>> 0) / 4294967296; };
const mean = (xs) => xs.reduce((s, v) => s + v, 0) / xs.length;
const median = (xs) => { const s = [...xs].sort((p, q) => p - q); const m = s.length / 2; return s.length % 2 ? s[Math.floor(m)] : (s[m - 1] + s[m]) / 2; };
const stat = useMedian ? median : mean;
const boots = [];
for (let b = 0; b < B; b++) {
  const sample = data.map(() => data[Math.floor(rand() * data.length)]);  // 복원 추출
  boots.push(stat(sample));
}
boots.sort((p, q) => p - q);
const lo = boots[Math.floor(0.025 * B)], hi = boots[Math.ceil(0.975 * B) - 1];
const se = Math.sqrt(boots.reduce((s, v) => s + (v - mean(boots)) ** 2, 0) / (B - 1));
table([['원래 표본의 통계량', stat(data).toFixed(2)], ['부트스트랩 표준오차', se.toFixed(2)], ['95% 구간(백분위수)', `${lo.toFixed(2)} ~ ${hi.toFixed(2)}`]], ['항목', '값']);
const edges = [8, 11, 14, 17, 20, 23, 26];
bars(edges.slice(0, -1).map((e, i) => `${e}~${edges[i + 1]}`), edges.slice(0, -1).map((e, i) => boots.filter((v) => v >= e && v < edges[i + 1]).length));
result(Number(lo.toFixed(2)));
```

### 예제 2. 순열 검정 (정확한 계산)

옛 방식 처리 시간(분): 12, 15, 9, 22, 14, 11, 13, 16 (평균 14.0)
새 방식 처리 시간(분): 10, 9, 12, 8, 11, 13, 9, 10 (평균 10.25)

관측 차이 = 14.0 − 10.25 = 3.75분.

1. 16개 값을 8개 / 8개로 나누는 방법은 $\binom{16}{8} = 12{,}870$가지.
2. 모든 배치에서 두 묶음 평균 차이를 계산한다.
3. 차이의 절댓값이 3.75 이상인 배치: 274가지.
4. p-value = 274 / 12,870 ≈ **0.021**.

효과가 없다면 이 정도 차이가 날 확률은 약 2.1%다. 같은 데이터의 t검정 p-value(0.026)와 비슷하다. 순열 검정은 정규분포를 가정하지 않는다. 숫자는 설명용이며, 전후 비교라면 다른 동시 변화의 가능성도 따져야 한다(STAT-CAUSAL-001).

## 7. 시각화와 해석

부트스트랩 통계량 수천 개를 **히스토그램**으로 그리고, 원래 추정값과 구간 끝을 세로선으로 표시한다. 모양이 종 모양이면 공식 구간과 비슷하고, 한쪽으로 치우치면 비대칭 구간이 필요하다는 신호다. 순열 검정은 섞어서 얻은 차이의 히스토그램에 관측 차이를 세로선으로 그어, 그 바깥 넓이가 p-value임을 보여 준다. 모델 비교에서는 두 모델의 지표 차이에 대한 부트스트랩 구간을 막대와 오차 막대로 그리면 "차이가 0을 넘는가"가 한눈에 보인다(데이터 시각화 원칙, STAT-VIZ-001).

## 8. 기술 비교 및 선택 기준

| 방법 | 가정 | 장점 | 맞는 경우 |
|---|---|---|---|
| 공식(t 구간, z 검정) | 정규성 또는 큰 표본 | 빠름, 해석 쉬움 | 평균·비율, 표본이 충분 |
| 부트스트랩 | 표본이 모집단을 닮음, 관측이 독립 | 어떤 통계량이든 가능 | 중앙값, 지표 차이, 비율의 비, 모델 성능 |
| 순열 검정 | 귀무가설에서 교환 가능 | 분포 가정 거의 없음, 정확 | 두 집단 비교, 작은 표본, 실험 데이터 |
| 블록·그룹 부트스트랩 | 블록 안 의존, 블록 간 독립 | 의존성 반영 | 시계열, 같은 사용자의 여러 값 |
| 베이즈 추론(STAT-BAYES-001) | 사전 분포·모형 | 사전 지식 반영, 확률 해석 | 작은 데이터 + 사전 정보 |

## 9. 실무 사례

- **모델 평가 지표의 신뢰구간:** 테스트 세트 문장(또는 문서)을 복원 추출해 정확도·F1·WER을 다시 계산하면 지표의 구간을 얻는다. 두 모델을 같은 세트로 비교하면 같은 표본 묶음에서 두 지표의 차이를 계산한다(짝지은 부트스트랩).
- **A/B 테스트의 중앙값·비율 지표:** 매출 중앙값, 사용자당 평균처럼 공식이 복잡한 지표에 부트스트랩을 쓴다. 사용자 단위로 다시 뽑아야 한다(같은 사용자의 여러 행이 의존).
- **LLM 평가:** 질문 세트로 두 프롬프트·모델의 점수를 비교할 때, 질문 단위 부트스트랩으로 차이가 우연인지 확인한다(LLM 응용 평가, AI-LLMEVAL-001).
- **배깅:** 부트스트랩 표본마다 모델을 학습해 평균을 내면 분산이 줄어든다. 랜덤 포레스트의 원리다(AI-TREE-001).

## 10. 기존 프로젝트와의 연결

아래 사실은 포트폴리오·저장소 원문(`content/profile.json`)에서 옮긴 것이다.

- **STT — WER 0.226 vs 0.239:** 같은 6,000문장으로 4종을 평가했다. 점검 질문: NeMo와 Whisper-small-ko FT의 WER 차이 0.013은 문장 표본이 바뀌어도 유지될 만큼 확실한가? 문장 단위 짝지은 부트스트랩(문장 6,000개를 복원 추출, 매번 두 모델의 WER 차이 계산, 2,000회)으로 95% 구간을 구하면 답할 수 있다. 문장마다 단어 수가 다르므로, 문장별 WER의 평균이 아니라 "전체 오류 단어 수 ÷ 전체 단어 수"를 매번 다시 계산해야 원래 지표와 같은 정의가 된다.
- **STT — 의미 지표 차이:** 의미 유사도 0.917 vs 0.934, SemWER@0.85 0.0776 vs 0.0664도 같은 방식으로 구간을 낼 수 있다. eval_clean과 eval_other를 나눠서 보면 어려운 음성에서 차이가 커지는지도 알 수 있다.
- **STT — 모델 선택 판단:** "정확도 중심 후보는 NeMo, 실시간 입력 후보는 Riva Streaming"으로 구분했다. 차이의 구간이 0을 포함하면 정확도로는 사실상 동률이므로, 속도(RTF)·운영 비용이 결정 기준이 된다는 근거를 더할 수 있다.
- **Preflight·DeepVi:** 부트스트랩·순열 검정을 쓴 기록은 없다.

## 11. 가정·한계·흔한 오해·트레이드오프

- **오해: 부트스트랩은 데이터를 늘려 준다.** 새 정보를 만들지 않는다. 가진 표본의 흔들림을 재는 도구일 뿐이다.
- **작은 표본:** 표본이 작으면 표본이 모집단을 잘 대표하지 못하고, 백분위수 구간이 너무 좁게 나오는 경향이 있다(예제 1에서 t 구간보다 좁음). 표본이 20~30개 미만이면 해석에 주의한다.
- **의존성:** 시계열이나 같은 대상의 반복 측정을 값 단위로 다시 뽑으면 의존 구조가 깨져 구간이 너무 좁아진다. 블록이나 그룹(대상) 단위로 뽑는다.
- **극단 통계량:** 최댓값·최솟값의 부트스트랩은 표본 최댓값을 넘지 못해 틀린다.
- **순열 검정의 조건:** 귀무가설 아래에서 이름표를 바꿔도 되는 구조여야 한다(무작위 배정 실험이면 자연스럽다). 관찰 데이터에서는 p-value가 인과를 뜻하지 않는다.
- **난수:** 결과가 시드에 따라 조금씩 달라진다. 시드와 반복 횟수를 기록하고, 결론이 시드에 따라 바뀌면 반복을 늘린다.
